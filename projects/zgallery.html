zGallery

Elegant Image Viewer

Browse, view, and lightly edit images on your Mac — without switching to a separate file manager.

See images. Manage them in place.

zGallery combines fast image browsing with the file actions you need — copy, move, delete, drag and drop — so viewing and organizing stay in one place.

Browse quickly

Thumbnail browsing for common image types (and video thumbnails), plus a folder tree to move through disks without losing context.

View the way you want

Zoom, fullscreen, and slideshow make it easy to review photos and image collections at speed.

Edit and organize

Rotate, flip, resize, change format, extract GIF frames, set wallpaper, and manage files with Finder-like drag and drop.

Browsing

Thumbnails and folders that stay out of the way.

Open a folder and move through images with thumbnail browsing and a tree panel. Folder thumbnails help you spot collections quickly.

  • Common image formats supported
  • Thumbnail browsing, including video thumbnails
  • Folder tree and folder-with-images thumbnails

Viewing

Zoom, fullscreen, slideshow.

Review images comfortably — zoom in and out, go fullscreen, or run a slideshow when you need to go through a set of photos.

  • Zoom in / out
  • Fullscreen mode
  • Slideshow

Editing & files

Light edits and file actions in one app.

Rotate, flip, resize, convert format, extract frames from animated GIFs, set the desktop wallpaper, and copy, move, or delete — including Copy & Paste and Drag & Drop like Finder.

How it works

  1. 1

    Open a folder

    Browse with thumbnails and the folder tree to find the images you need.

  2. 2

    View and review

    Zoom, go fullscreen, or start a slideshow to move through the set.

  3. 3

    Edit or organize

    Apply light edits, set wallpaper, or copy, move, and delete without leaving zGallery.
